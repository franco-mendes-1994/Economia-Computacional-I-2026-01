
Faça um programa plenamente modularizado que seja uma calculadora com as quatro operações fundamentais.  A calculadora deve ser capaz de operar com números complexos, ler dois números dados pelo usuário, seguida da operação desejada pelo usuário e colocar na tela a resposta 

A calculadora deve executar em interface de linha de comando e ficar disponível para novo cálculo ao fim da execução de uma operação a menos que o usuário digite a palavra FIM.

O programa deve conter, no máximo, 20 módulos e não possuir mais de 16 MB.
