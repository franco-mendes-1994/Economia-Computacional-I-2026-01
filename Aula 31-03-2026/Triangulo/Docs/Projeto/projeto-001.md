## Projeto de estruturas de dados

triangulo - [area -tipo real, base - tipo real, altura - tipo real] é uma lista

## Projeto do algoritmo

1. Alocação de memória - Alocar memória para a variável triângulo,
2. Entrada de dados - ler os dados do triângulo
3. Processamento de dados - usar a fórmula da área de um triângulo  area = (0.5)*base*altura
4. saída - colocar na tela o resultado
