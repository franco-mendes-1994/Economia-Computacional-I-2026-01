## Projeto de estruturas de dados

altura - tipo real
area - tipo real
base - tipo real
contador - tipo inteiro
parte_maior - tipo real
parte_menor - tipo real
triangulo - [lado1 - tipo real, lado2 - tipo real, lado3 - tipo real] é uma lista


## Projeto do algoritmo

1. Alocação de memória - Alocar memória para a variável triângulo,
2. Entrada de dados - ler os lados do triângulo
3. Processamento
   1. Definir qual lado do triangulo será usado como base - base = lado1
   2. Calcular parte_menor e parte_maior
   3. Usar a formula altura**2 = parte_menor*parte_maior para calcular a altura do triangulo a partir da base definida no item anterior
   4. Usar a formula area = (0.5)*base*altura
4. saída - colocar na tela
